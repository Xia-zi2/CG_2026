# USTC CG 2026

This repository collects my USTC Computer Graphics 2026 homework code, reports,
and final project materials.

## Layout

- `Homeworks/`: homework submissions organized in course order.
- `Final/`: final project upload package already present in this repository.

Each homework directory uses the same basic structure when applicable:

- `src/`: modified or newly added source files, kept with their original
  framework-relative paths.
- `report/`: reports and report figures extracted from the submitted packages.
- `results/`: selected generated outputs.
- `submission/`: original submission archive when the archive contains local
  files rather than only a cloud-drive link.
- `cloud_link.md`: USTC cloud-drive link when the original submission package
  was a text-only link.

## Source Basis

The homework folders were organized against the official course repository:

- Official course repo: https://github.com/USTC-CG/USTC_CG_26
- Official homework tree: https://github.com/USTC-CG/USTC_CG_26/tree/main/Homeworks

Generated build directories, caches, model checkpoints, large datasets, and
other local temporary files are intentionally omitted unless they were part of
the submitted report package.
